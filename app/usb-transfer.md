# עבודה בבית ובמרפאה

**כדי להשאיר שני מחשבים פעילים, רוכשים שני רישיונות באותו חשבון.** מחיר ClinicFlow Full הוא 1,499 ₪ בתשלום חד־פעמי לכל מחשב. שני מחשבים עולים יחד 2,998 ₪. אם כבר רכשתם רישיון אחד, התשלום הנוסף הוא 1,499 ₪ בלבד.

## איך מוסיפים מחשב?

1. היכנסו לאותו חשבון ב[לוח הבקרה של ClinicFlow](https://www.clinic-flow.co.il/dashboard).
2. בחרו **רכישת רישיון למחשב נוסף**. אחרי התשלום חזרו ללוח הבקרה ובדקו שמספר הרישיונות גדל. אם חויבתם והמספר טרם התעדכן, פנו אלינו לפני שתנסו לשלם שוב.
3. התקינו את הגרסה התומכת במספר מחשבים בשני המחשבים. במחשב הנוסף, התחברו לאינטרנט והפעילו את התוכנה באותה כתובת דוא״ל ובאותה סיסמה. הגדירו קוד PIN מקומי כשתתבקשו.
4. השאירו את המחשב הראשון מחובר לרישיון שלו. אם במסך ההפעלה מופיעה הצעה **להעביר** אליו רישיון ממחשב אחר, עצרו ובדקו את הגרסה ואת מספר הרישיונות בחשבון. העברה מיועדת להחלפת מחשב. בהתקנה ותיקה ייתכן שתופיע האפשרות **הגדרות ← רישיון ← אימות המחשב בחשבון**.

אפשר להוסיף בדרך זו גם מחשב שלישי. לאחר ההפעלה הראשונית נכנסים בכל מחשב בקוד המקומי ועובדים גם ללא אינטרנט. מחשב כבוי או מנותק יוכל לקבל שינוי במצב הרישיון לאחר שייפתח ויצליח לבדוק את הרישיון באינטרנט. פתיחת האפליקציה במרפאה משאירה את הרישיון הנוסף בבית פעיל.

## איך ממשיכים בבית את הביקור שנכתב במרפאה?

החשבון המשותף מנהל את הרישיונות. הביקורים, התורים והמסמכים נשמרים בתיקייה מקומית בכל מחשב. אם תרצו לראות בבית את העבודה מהמרפאה, העבירו גיבוי מוצפן. ה־USB משמש לנשיאת הקובץ בין המחשבים. השאירו לכל התקנה תיקיית נתונים נפרדת.

**לדוגמה**, ביום ראשון סיימתם ביקור במרפאה. צרו שם גיבוי, סגרו את האפליקציה, והעבירו את הקובץ הביתה. אחרי השחזור בבית, ודאו שהביקור של יום ראשון מופיע לפני שאתם עורכים אותו. אם הוספתם הערה בבית, צרו גיבוי חדש בבית והחזירו אותו למרפאה **לפני תחילת העבודה ביום שני**.

## העברת גיבוי באמצעות USB

1. במחשב שבו נעשתה העריכה האחרונה, שמרו את הביקור. ודאו שברשותכם **מפתח השחזור של המשתמש המקומי במחשב המקור**. אפשר לנהל אותו תחת **הגדרות ← אבטחה**. אם הנפקתם קוד חדש, צרו אחר כך גיבוי חדש ושמרו את הקוד בנפרד מהכונן.
2. פתחו **גיבויים ← גיבוי ידני עכשיו**, הגדירו סיסמת גיבוי בת 8 תווים לפחות ואמתו אותה. בחרו **יצירת גיבוי** והמתינו להודעת הצלחה. העתיקו את קובץ ה־`.cfbk` לכונן ה־USB ושמרו עותק נוסף במקום בטוח. סגרו את האפליקציה במחשב זה.
3. במחשב היעד השתמשו בגרסה תואמת או חדשה יותר. אם כבר יש בו מידע, צרו גם בו גיבוי נפרד לפני השחזור. בדקו את התאריך ושעת היצירה של הקובץ שבכוונתכם לשחזר.
4. פתחו **גיבויים ← שחזור מגיבוי**, בחרו את הקובץ מהכונן והזינו את סיסמת הגיבוי. בשחזור מרפאה למחשב חדש, פתחו **שחזור גישה במחשב חדש**, הזינו את קוד השחזור המקורי ובחרו PIN למחשב היעד.
5. בחרו **בדיקת סיסמה** ולאחר מכן **שחזור**. **החלפה מלאה מחליפה את המידע במחשב היעד בתוכן הגיבוי.** אשרו אותה רק אחרי שווידאתם שזו הגרסה העדכנית של המרפאה ושמרתם את עותק היעד.
6. בסיום, סגרו ופתחו את ClinicFlow והיכנסו עם ה־PIN החדש במחשב היעד. פתחו ביקור מוכר ואת אחד הקבצים המצורפים אליו ובדקו שתוכנו מופיע. כעת המשיכו לעבוד בעותק הזה.

**אם כבר ערכתם את אותה מרפאה בשני המחשבים מאז הגיבוי האחרון**, עצרו לפני שחזור או החלפה. צרו גיבוי נפרד בכל מחשב וסמנו איזה עותק הגיע מהבית ואיזה מהמרפאה. מיזוג אינו מבטיח ששתי עריכות של אותו ביקור יישמרו. פנו לתמיכה עם גרסאות התוכנה וזמני הגיבויים, ללא שמות מטופלים או קובצי גיבוי במייל.

## איך מנפיקים חשבוניות וקבלות בשני מחשבים?

כל עותק של המרפאה מנהל את מספור המסמכים שלו. אם משחזרים את אותו גיבוי בשני מחשבים ומנפיקים חשבוניות במקביל, עלול להיווצר אותו מספר חשבונית בשני העותקים. כדי להמשיך סדרת מספור אחת, הנפיקו מסמכים מעותק העבודה העדכני. לפני הנפקה במחשב השני, העבירו אליו את הגיבוי האחרון ובדקו שהמסמך האחרון שהנפקתם מופיע בו.

## ומה עושים אם המחשב הישן התקלקל?

אם מחליפים מחשב ומפסיקים לעבוד בקודם, ניתן להעביר אליו את הרישיון הקיים. אם המחשב הישן זמין, גבו תחילה ובחרו **הגדרות ← רישיון ← ניתוק מחשב זה**. אם הוא אבד, התקלקל או שיש בחשבון כמה מחשבים וקשה לזהות איזה מהם לנתק, פנו לתמיכה. חשבון האתר מאפשר להוריד מחדש את התוכנה. שחזור התיקים דורש גיבוי שמור ואת פרטי השחזור המתאימים. גיבויים אוטומטיים ישנים עשויים לדרוש את המחשב המקורי.
